# Examples convention — core

> 🚧 This page will document the examples layout for core: naming rules, and when to use subdirectories.
>
> Reference: [QVAC SDK examples](https://github.com/tetherto/qvac/tree/main/packages/sdk/examples).

Core has no per-scenario examples tree. The end-to-end example is [`examples/mvp-site/`](../../../examples/mvp-site/README.md),
and a single Worker runs against its bundled mock through `npm run mock` plus the boot script in its guide, for example
[run an Avalon Worker](../../../docs/guides/miners/run-avalon-worker.md).
